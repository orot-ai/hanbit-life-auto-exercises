# 코딩 몰라도 인생자동화 됩니다 — 실습자료

한빛미디어 도서 『코딩 몰라도 인생자동화 됩니다』의 실습자료 사이트입니다. 현재 공개 자료는 5장, 6장, 8장과 11·12장 공통 음원입니다.

## 로컬 확인

```bash
python3 -m http.server 4173 --directory .
```

브라우저에서 `http://127.0.0.1:4173`을 엽니다.

## 페이지 구조

| 주소 | 역할 |
|---|---|
| `/` | 5장, 6장, 8장, 11장 선택 |
| `/5/` | PRD 다운로드와 실습 순서 |
| `/5/example/` | 실습 후 비교하는 완성 HTML 목업 |
| `/6/` | 예제 다운로드 폴더와 결과확인표 |
| `/8/` | 일정과 자료 전달이 담긴 예제 녹음 |
| `/11/` | 11·12장에서 함께 사용하는 후속 통화 녹음 |

홈에는 다운로드 링크를 두지 않습니다. 5장 페이지도 PRD를 주 자료로 먼저 보여주고, 완성 목업은 `완성 예시 보기`로 분리합니다.

## 자료 대응

| 장 | 시점 | 자료 |
|---|---|---|
| 5장 | 실습 시작 | `인생자동화대시보드_PRD.md` 다운로드 |
| 5장 | HTML 목업 제작 후 | `/5/example/` 완성 예시 |
| 6장 | 실습 시작 | `예제_다운로드_폴더.zip` 다운로드 |
| 6장 | 파일 정리 후 | `결과확인표.pdf` 다운로드 |
| 8장 | 실습 시작 | `예제_녹음.m4a` 다운로드 |
| 11장 | 실습 시작 | `후속통화_예제.m4a` 다운로드, 12장에서 재사용 |

제작 정본 `인생자동화대시보드_PRD_요청프롬프트.md`는 5장 원고에 들어가는 제작 자료이며 현재 사이트 다운로드 대상이 아닙니다. 원고 전체 작성 완료 후 별도로 제작할 `프롬프트 모음`에 반영할 예정이므로, 현재 사이트의 공개 자료 누락이 아닙니다.

후속 통화는 11장에서 한 번 내려받고 12장도 같은 파일로 이어갑니다. 공개 파일은 검수한 교육용 음원 한 건이며 대본, 판단 정답, 기준 문서와 내부 검수 자료는 배포하지 않습니다. 기존 5·6·8장 자료는 그대로 유지합니다.

## 검증

```bash
node scripts/verify-site.mjs
```

필수 페이지와 링크, 공개 파일 범위, 기존 5장·6장·8장 자료와 새 후속 통화의 제작 정본 SHA-256 일치, Vercel 설정을 확인합니다. 기존 제작 정본은 저장소 옆 `../output/실습자료`에서 읽습니다. 후속 통화 정본은 같은 작업 root의 `hanbit-manuscript/작업본/11장/examples/후속통화_예제.m4a`에서 읽으며, 다른 checkout에서는 `HANBIT_FOLLOWUP_AUDIO`로 정본 위치를 지정할 수 있습니다.

## 배포 상태

Vercel 운영 주소는 <https://life-auto.vercel.app>입니다. 2026-09-28 API 확인 기준으로 기존 프로젝트 `orot-ais-projects/life-auto`는 Git 연결이 없으며 CLI로 배포합니다. Git push만으로 운영이 갱신된다고 가정하지 않습니다.

사이트 저장소 루트에서 기존 프로젝트에 연결하고 검증한 파일을 배포합니다. 원고·제작 정본을 보관한 상위 폴더를 배포하지 않습니다.

```bash
vercel link --yes --project life-auto --scope orot-ais-projects
node scripts/verify-site.mjs
vercel --prod --yes --scope orot-ais-projects
```

배포 뒤 운영 페이지, 음원 전체 SHA-256, 다운로드 헤더와 Range 응답을 확인합니다. 기존 다운로드 네 종과 기존 장 페이지·공통 자산은 이전 운영본과 같아야 합니다.
