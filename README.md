# 코딩 몰라도 인생자동화 됩니다 — 실습자료

한빛미디어 도서 『코딩 몰라도 인생자동화 됩니다』의 장별 실습자료 사이트입니다.
첫 화면에서 현재 읽는 장을 고르면 해당 장의 자료만 보여줍니다.

## 로컬 확인

```bash
python3 -m http.server 4173 --directory .
```

브라우저에서 `http://127.0.0.1:4173`을 엽니다.

## 페이지 구조

| 주소 | 역할 |
|---|---|
| `/` | 4·7·9·11장 선택 |
| `/4/` | 받을 파일이 없다는 안내 |
| `/7/` | 다운로드 폴더 예제와 결과확인표 |
| `/9/` | 예제 녹음 한 건 |
| `/11/` | 예제 녹음 세 건 모음 |

홈에는 다운로드 링크를 두지 않습니다.

## 자료 대응

| 장 | 시점 | 파일 |
|---|---|---|
| 7장 | 실습 1 시작 전 | `예제_다운로드_폴더.zip` |
| 7장 | 실습 4, 정리 완료 후 | `결과확인표.pdf` |
| 9장 | 실습 1 | `예제_녹음.m4a` |
| 11장 | 실습 1, 10장 완료 후 | `예제_녹음_모음.zip` |

4장에서는 자료실 위치만 확인하며 파일을 받지 않습니다.

## 검증

```bash
node scripts/verify-site.mjs
```

사이트 링크, 파일 존재 여부, 배포 폴더와 제작 정본의 SHA-256 일치 여부를 확인합니다.
