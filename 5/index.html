대시보드 PRD

아래 파일 하나를 내려받은 뒤 책의 순서대로 실습합니다.

  1. PRD 내려받기제품 요구사항을 내 컴퓨터에 저장합니다.
  2. 코덱스에 건네기연결한 대시보드 폴더로 PRD를 옮겨달라고 말합니다.
  3. HTML 목업 만들기코덱스가 폴더 안에 단일 HTML 파일을 만듭니다.
  4. 브라우저에서 확인하기HTML 파일을 열어 화면과 동작을 살펴봅니다.
